2. The idea in two languages

In plain words

Imagine you have a list of F-061 numbers for ordinary bowing (arco normal), note by note. For muted playing you only have some of those notes. STE Lab does not invent a new physics and does not claim F-061 is “brightness.” It asks: on the notes we have in both lists, how much did the mute change F-061? Then it applies that same change to the notes we lack. Every invented number is painted as “modelled”, never as “measured.”

For the specialist

Let S(m) be the F-061 Combined Density Metric (spectral mass) of the source technique at sounding MIDI m, and T(m) the same metric for the target technique. On the measured overlap, define the log-ratio field L(m) = ln(T(m)/S(m)). L is interpolated with a monotone cubic (PCHIP) inside the overlap and held constant outside it (no cubic extrapolation). The reconstruction is T̂(m) = S(m) · exp(L̂(m)), with L̂ clipped to [−3, 3] as a numerical guard. Origin tags travel with every cell.

The one rule that must not be broken

A cell that was filled, transferred, or averaged is never relabelled measured. Principal evidence for a string effect is the sheet Empirical_ORCH (Orchidea cells tagged measured — every recorded dynamic, not only mf). On woodwind ordinario, principal empirical cells are the target-instrument Iowa measurements. Completed-grid Media is a convenience and its rule depends on family (§5.6). Sul tasto is not invented. String rows above the measured-anchor ceiling (violin: MIDI 100, E7) stay visible and are excluded from aggregate summaries. Genuine woodwind Iowa notes above catalog sounding_high are kept.

3.3 What is a “layer”?

In plain words

A layer is one column of a thought-experiment: “the violin, in the Orchidea library, muted, played mezzo-forte.” You may have several layers in one session (IOWA muted pp, ORCH muted pp, Media, …). You never mix two dynamics or two techniques in the same layer.

For the specialist

A Layer is a map MIDI → Cell(value, origin, PI95, reporting_status, …). Identity fields (instrument, collection, technique, dynamic, pitch_basis) are written onto every exported row. sounding_concert is the working pitch basis; written pitch is stored only as optional metadata.

3.4 Putting numbers in (the part people get wrong)

Always: Tab 1 → New source layer, then Tab 2. The paste goes into the box labelled Block paste.

  • Two columns (note and value), tab- or comma-separated: G3 33.42
  • Three columns: note, value, origin (measured, modelled_IOWA_anchored, …)
  • Values only: a list of numbers. You must set “Start note if the paste is only numbers”, or the program cannot know where G3 is.
  • A bare integer such as 72 is a value, not MIDI 72. Write midi72 if you mean the pitch.

Buttons: Parse clipboard reads what you copied; Parse box and place commits the box onto the selected layer; Clear empties the box only (the layer is untouched).

If slot occupied: prefer_measured keeps a measured cell when a modelled one arrives; overwrite replaces; skip leaves the old cell.

3.8 Two scientific workflows (do not mix them)

In plain words

Violin, viola, cello and double bass are one kind of job: find every real effect folder (harmonics, sul ponticello, con sordino, …) and write a separate pair of workbooks for each, plus ordinario. Bass clarinet is another kind of job: keep every genuine Iowa note, estimate the missing Orchidea spine from the clarinet family, and never invent a mute or ponticello book.

For the specialist

4.1 Reconstruct IOWA con sordino from Orchidea measurements

4.4 Things you should not do

  • Do not treat Philharmonia or McGill as a third vote in Media. They are context, not a TIER peer of IOWA/ORCH in this pipeline.

  • Do not pool F7–B7 into a geometric mean. They sit above the measured-anchor ceiling.
  • Do not invent viola sul tasto.

5. Processes, methods and formulas (as implemented)

This section states the mathematics the code actually evaluates. Symbols match ste_lab/transfer.py, ste_lab/calibration.py, ste_lab/empirical.py, run_ste_from_preparatory.py and build_ste_preparatory.py. Natural logarithms: np.log is ln, not log10.

5.1 Notation

SymbolMeaning in the code
mSounding concert MIDI (integer).
S(m)Source CDM (usually ordinario / arco) at m. Must be > 0.
T(m)Measured target-technique CDM at m. Must be > 0.
L(m)Log-ratio at an anchor. Python: np.log(target / source).
L̂(m*)Interpolated / held log-ratio at any MIDI m* on the source curve.
T̂(m*)Reconstructed target CDM from S · exp(L̂). Origin stays modelled. Distinct from a recorded Orchidea cell, which is T, not T̂.
MAnchor set: pairs with S(m)>0 and T(m)>0, sorted by MIDI.
mlo, mhimin and max MIDI in M.
dDynamic: pp, mf or ff in the preparatory runner.

5.2 Process (order of operations)

  1. Locate sources. Strings — IOWA (and arco ORCH spines): Zenodo collections workbook, Media columns IOWA d / ORCH d, else IOWA by-string sheet CDM − Media. Woodwinds — IOWA: every target compiled research book under an Iowa-named tree (plus any Iowa cells already on a source media book, merged). Effects (ORCH / Phil / McGill): *compiled_density_metrics_research.xlsx under a folder whose name contains _sustains_stable; sheet Research_Core else Spectral_Density_Metrics; columns note, spectral_mass.
  2. Merge every matching compiled book per (collection, technique, dynamic). Longest-file-wins is prohibited. Identical values (relative 10−6) collapse and provenance lists all files. Material disagreement → EMPIRICAL_CONFLICT: that MIDI is not silently averaged and is not exported.
  3. Build anchors on the MIDI intersection of teacher effect and teacher arco (same dynamic). One block per recorded dynamic when Orchidea has pp/mf/ff. Drop m below the harmonics floor when the effect is harmonics. Skip sul tasto.
  4. Orchidea recorded layer (orchidea_recorded_layer): if a compiled book exists for that instrument × effect × dynamic, copy those cells as measured. Do not apply L, do not fill holes. That recording is the ORCH layer.
  5. Teach L from the anchors of that dynamic (else from mf) for collections that have no recording.
  6. IOWA (and any unrecorded Orchidea dynamic): T̂ = S · exp(clip L̂) on that collection’s own arco. Origin stays modelled. Same-dynamic anchors are used when ≥ 3 pairs exist; otherwise mf L is inherited (not a new experiment).
  7. Media: family-specific (§5.6). Strings average available IOWA/ORCH peers. Woodwind ordinario keeps a measured target cell (empirical_only).
  8. Export STE + Zenodo workbooks. Origin tags travel with every cell. Woodwind ordinario books also receive Measured_Data, Final_Calibration, Validation, Methodology.

Instrument selects the family runner even when Rebuild is off. It still does not load another deposit’s trees: if the preparatory path contains “viola” and Instrument is cello, the log prints a WARNING and the numbers remain those of that Excel. With Rebuild ticked, discovery hunts Look in folder. Changing Instrument only suggests a default folder.

5.3 Anchor log-ratio — _safe_log_ratio

ste_lab/transfer.py · _safe_log_ratio

If S(m) ≤ 0 or T(m) ≤ 0, the pair is discarded. Otherwise:

L(m) = ln (T(m) / S(m)) = ln T(m) − ln S(m)

Code: np.log(target / source). Rebuild stores this L on Anchors_all (one block per recorded dynamic) and on All_effects_mf (L_harmonics, L_ponticello, L_sordino or L_sordino_McGill). Those columns teach IOWA and any unrecorded Orchidea dynamic. They are not applied to a recorded Orchidea layer.

5.4 Interpolation of L̂ — _interp_log_ratio

ste_lab/transfer.py · _interp_log_ratio · scipy.interpolate.PchipInterpolator

Let the usable anchors be sorted (m1, L1), …, (mn, Ln) with n = |M|, mlo = m1, mhi = mn.

nInterior m* ∈ [mlo, mhi]Exterior
1L̂(m*) = L1 for every m*same constant
2Linear interpolation: np.interp(m*, [m1, m2], [L1, L2])hold-edge (below)
≥ 3Monotone cubic PCHIP (Fritsch–Carlson), extrapolate=Falsehold-edge (below)

Hold-edge (the code does not continue the last cubic segment):

L̂(m*) = L(mlo)   if m* < mlo

L̂(m*) = L(mhi)   if m* > mhi

PCHIP with extrapolate=True was retired. It produced L ≈ −20…−40 off the last pair; after the clip below that became S · e−3 ≈ 0.05 S (the near-zero high notes).

5.5 Reconstruction — technique_transfer / transfer_or_copy

ste_lab/transfer.py · technique_transfer  |  np.exp(np.clip(L, −3, 3))

For every MIDI m* that exists on the source layer:

r(m*) = exp ( clip(L̂(m*), −3, 3) )

T̂(m*) = S(m*) · r(m*)

clip is numpy.clip: L̂ is replaced by −3 if L̂ < −3, by +3 if L̂ > 3. The cell is dropped if T̂ is not finite or T̂ ≤ 0.

Equivalent reporting identity (not stored as a separate column in the runner):

100 · (T̂/S − 1) = 100 · ( eclip(L̂,−3,3) − 1 ) %

The preparatory runner calls this with copy_anchors=False for IOWA and for an Orchidea dynamic that was not recorded: even at an anchor MIDI, T̂ = S · r, origin modelled_IOWA_anchored / modelled_ORCHIDEA_anchored.

run_ste_from_preparatory.py · orchidea_recorded_layer

Orchidea recorded (any instrument, effect, dynamic): if Paste_effects_mf has a column ORCH_{slug}_{d} with cells, the ORCH layer is exactly those cells:

T(m, d) = Tmeas(m, d), origin = measured

No L, no hole-fill. Harmonics still drop m below the instrument floor. Sul tasto columns are ignored.

Unrecorded Orchidea dynamic (typical harmonics / ponticello pp and ff; viola mute): reuse the donor (usually mf) or same-dynamic anchor field on that dynamic’s arco:

T̂(m, d) = S(m, d) · exp( clip(L̂donor or d(m), −3, 3) )

That inherited ratio is a transfer identity, not a new dynamic calibration.

Harmonics floor: any cell with m < mfloor is deleted after transfer. Preparatory runner follows Instrument: violin 79, viola 72, cello 60, double bass 52.

5.6 Media — family-specific production resolver

ste_lab/media_policy.py · resolve_iowa_orch_pair / production_media_of  |  run_ste_from_preparatory  |  GUI Average

Bowed-string effect and ordinario books (string arithmetic mean of production collections only). At each MIDI m, let V(m) be the present IOWA and ORCH values. Philharmonia and McGill are context layers and are never added to this mean.

μ(m) = (1/k) Σj=1k vj(m)

If only one collection has m, μ(m) equals that value (not half of it). If neither is present, the cell is missing, not zero. Shared technique-transfer L̂ means a string mean is not a second independent measurement of the effect.

Woodwind ordinario follows calibration.yaml combination. Default empirical_only: keep a valid target empirical value; use a valid transfer value only when the empirical value is absent. Supported alternatives: equal_weight (0.5/0.5) and legacy_equal_weight with the rule wT = 1 − wE. fixed_weight and validation_optimised are rejected until they have a validated specification. optimal_weight() is a research helper only. A blended output is COMBINED_ESTIMATE, not MEASURED.

The same resolver writes in-memory Media, Zenodo Media literals or matching Excel formulas, AcousticTable, and Final_Calibration. Per-row weights are the effective weights; configured weights are exported separately.

5.7 Other methods (full Lab only; not the preparatory runner)

Global linear ratio (method="linear_ratio"):

ρ = mediani ∈ M ( T(mi) / S(mi) )

T̂(m*) = T(m*) if m* is an anchor, else S(m*) · ρ

Family transfer, concert pitch: same MIDI; scale = median of overlap ratios if anchors were given, else 1.

T̂(m) = S(m) · ρfamily

Family transfer, register-relative:

m' = mtarget low + (m − msource low)

T̂(m') = S(m) · ρfamily

Fill missing notes on one layer (fill_missing), default method pchip on the CDM values (not on L). Interior of the measured MIDI span is labelled interpolated. Exterior cells may be written up to ± max_extrap_semitones (default 12): PCHIP uses extrapolate=True and origin extrapolated_pchip (not ridge regression) and requires at least three known points; two-point PCHIP is rejected with no silent substitute. Linear uses NumPy endpoint hold outside the span and origin extrapolated_hold, not interpolated. Polynomial remains extrapolated_polynomial. Technique-transfer still holds edge L; that operator is separate and was not changed. The preparatory runner does not call fill_missing.

5.8 What the code does not compute

  • No invented viola sul tasto (no teacher pairs → no L).
  • No L on an Orchidea layer that was recorded (any instrument × effect × dynamic).
  • No second L from IOWA (IOWA has no effect recordings).
  • No pooling of Philharmonia or McGill into Media.
  • No cubic extrapolation of L beyond the last anchor. Pooled L (optional, §5.12) still interpolates/holds/clips with the same operator.
  • No replacement of a measured target cell by a transfer, a pooled field, or a validation interval.
  • String rebuild does not read Iowa _Sustains_Stable trees (Iowa remains on the Zenodo book). Woodwind rebuild does read target Iowa compiled trees and merges them.
  • No overwrite of a source workbook. No silent drop of a genuine compiled Iowa note merely because another file is longer or a note sits above catalog sounding_high.
  • No orchidea_family_transfer_estimate / two_log_ratio on ordinary string technique books.

5.9 Woodwind family-transfer calibration (ordinario only)

ste_lab/calibration.py · two_log_ratio_transfer · combine_empirical_and_modelled  |  calibration.yaml

Activated only when orchestral_group(instrument) == "woodwinds" on the ordinario export. Default config: transfer.method = two_log_ratio, combination.method = empirical_only. The 1.2.8 scalar median is retained only as legacy_target_calibrated and is labelled COMBINED_ESTIMATE, never TRANSFERRED.

Let the sibling (Bb clarinet) supply Iowa and Orchidea, and the target (bass clarinet) supply Iowa:

Lcoll(m) = ln(ORCHcl(m) / IOWAcl(m))

Linstr(m) = ln(IOWAtarget(m) / IOWAcl(m))

ORCHtarget(m) = ORCHcl(m) × exp( clip(Linstr(m), −3, 3) )

Lcoll and Linstr are the collection-kind and instrument-kind transfer relations of §5.10. They use the same hold-edge interpolator as technique transfer (§5.4). Iowa used to form Linstr is excluded from transfer validation. If there is no same-collection sibling overlap, Linstr is UNDETERMINED and no transfer cells are written. Default transfer_field.mode = single keeps today’s Iowa Linstr numbers bit-for-bit; pooled is optional (§5.12).

Lcoll is a stored diagnostic. Production does not multiply by exp(Lcoll). The predictor already starts from the ORCH sibling donor; at matched unclipped anchors, applying Linstr there is equivalent to applying the collection ratio to the Iowa target. That identity is not claimed for every interpolated or clipped MIDI.

empirical_only: a finite measured target value is the final value (weight 1 / 0). Transfer is used only when that cell is missing. equal_weight and legacy_equal_weight do mix both inputs; those blended outputs are COMBINED_ESTIMATE. fixed_weight and validation_optimised are rejected. Authoritative weights: wT = 1 − wE.

QA on Final_Calibration: HIGH / MODERATE are production-eligible; REVIEW_REQUIRED is visible but Accepted_Final=FALSE unless allow_review_required is true (default false); distance > 6 semitones is REJECTED. The notation catalog range (bass clarinet sounding 34–77) is not permission to delete a genuine measurement. The export grid is the catalog specification union the measured extrema.

5.10 Transfer relations

ste_lab/relations.py · Relation · discover_relations · select_production_relation

A transfer relation is a pair (source condition, target condition) measured inside one collection at shared sounding MIDI:

L(m) = ln(target(m) / source(m))

Three kinds are discovered today; any later kind (register, dynamic) uses the same record.

kindsource → targetWhere
techniqueordinario → effectOne collection (strings)
instrumentsibling → targetOne collection (woodwind Linstr)
collectionIOWA → ORCH (and other pairs in name order)One instrument / technique (woodwind Lcoll)

discover_relations walks every collection id present in the trees — the list is not hard-coded. Sul tasto is skipped. Harmonics honour the instrument floor. Relations with fewer than three same-dynamic pairs are kept on Relations_inventory; production still inherits mf L when n < 3. select_production_relation is the policy that reproduces today’s teacher: ORCH first; McGill con sordino only when ORCH has none; woodwind Iowa Linstr (else Philharmonia, then McGill); Lcoll is the IOWA→ORCH sibling pair and is stored, not multiplied.

5.11 Validation of the transfer assumption

ste_lab/validation.py · compare_relations

Always on, never a substitute for a measurement. For every (kind, instrument, source, target, dynamic) taught by two or more collections, each collection pair is compared on the MIDI intersection of their anchors (T>0 and S>0 only):

bias = mean(LA − LB),   MAE,   SD,   Pearson r,   bias% = 100 · (ebias − 1)

Per overlapping MIDI, min / max / range of L across collections. Sheets L_Validation, L_Spread, and Summary_Validation are written on every STE and Zenodo book; {instrument}_L_validation.csv sits in the output folder. Evidence_Map rows with evidence_role = validation mark non-production collections that contributed.

On a modelled cell only, and only where ≥ 2 collections overlap at that MIDI:

PI95 = value · exp( ± 1.96 · SD )

SD is the per-note SD of L when three or more collections overlap, or the relation-level SD of L differences when the note has a single pair. Those cells take uncertainty = empirical_spread. Every other cell is left untouched.

5.12 Pooled log-ratio field (optional)

calibration.yaml · transfer_field  |  ste_lab/relations.py · field_for_transfer

The published number is always the IOWA/Orchidea Media of §5.6. Extra collections do not add a third CDM term. They enrich that Media only by voting on L = ln(effect / ordinario) where their anchors overlap the teacher’s.

Default mode: pooled (1.5.0): at each MIDI with ≥ min_collections (default 2) overlapping anchors, L̂ is the mean of the per-collection L values, weighted by that collection’s anchor count (weight: anchors) or equally (weight: equal). That pooled list is then interpolated, held, and clipped exactly as §5.4. Where fewer collections overlap, the production teacher is kept (Orchidea; McGill sordino only if Orchidea has none) and the fallback is logged. Applies to technique, instrument, and collection relations (woodwinds pool Linstr and Lcoll separately).

mode: single is the 1.4.0 one-teacher field (bit-for-bit with the published books).

Invariants under both modes: a recorded Orchidea layer is copied as measured and never has L applied; woodwind empirical_only still keeps a measured target cell; string Media remains mean(IOWA, ORCH); Philharmonia / McGill absolute values never enter Media or a measured slot. Pooled modelled cells are tagged modelled_<COLL>_pooled; the cell comment, Session_Log (per MIDI), and WorkbookMeta / Provenance list the contributing collections and weights.

6. Technical manual (implementation notes)

6.1 The metric

In plain words

The number on every sheet is “how much sound-stuff is piled up in the spectrum” for a long, stable note. It is not loudness in decibels and not a count of harmonics by eye. Bigger means a denser, more populated spectrum. A mute usually makes it a little smaller; ponticello usually makes it larger; a natural harmonic makes it clearly smaller.

For the specialist

Working name: Combined Density Metric, research identifier F-061, stored as spectral_mass on Spectral_Density_Metrics / Research_Core. Unit in AcousticTable: cdm_technique_sustain_v1. It is not the older Legacy “Combined Density Metric” column (Orchidea G3 pp sordino is 33.42 on F-061 and ~22.5 on Legacy). Always read F-061 when pairing with the Zenodo ORCH series.

6.2 Pitch, MIDI, enharmonics

Working grid is sounding concert pitch. Spelling prefers flats (Ab, Eb) to match the Zenodo books. parse_pitch accepts G3, Ab3, G#3, midi55. Chromatic snap: a pasted note that is 14 cents sharp of G4 is stored as G4 (MIDI 67), not as a free-frequency row. Family transfer may use concert_pitch (shared sounding MIDI) or register_relative (align lowest sounding notes, then walk by index).

6.3 Log-ratio transfer (summary)

The identities evaluated by the code are written out in §5. Short form (strings): recorded Orchidea cells stay Tmeas; otherwise L = ln(T/S) on anchors; L̂ by PCHIP (or linear / constant) with hold-edge; T̂ = S · exp(clip(L̂, −3, 3)). Same-dynamic pairing is mandatory. copy_anchors=False on IOWA and on unrecorded Orchidea dynamics. Woodwind ordinario uses the two-log-ratio family transfer in §5.9, not this technique-transfer L.

6.4 Media, ceiling, evidence

  • F-061 is the project Combined Density Metric (spectral-density descriptor on sustains). It is not brightness, brilliance, “spectral richness,” or a count of audible harmonics. Report “F-061 decreased by x%,” then interpret with other descriptors if needed.
  • Empirical_ORCH (principal evidence on string books) = Orchidea cells whose Estimate is measured, at every dynamic that was recorded. Sul tasto does not appear. A dynamic that only inherited donor L does not appear there. On woodwind ordinario books the principal empirical sheet is target Iowa (Measured_Data), not a fake Orchidea recording of this instrument.
  • Evidence_Map lists IOWA / ORCH / Phil / McGill effect layers with n_measured, n_modelled, and evidence_role (empirical / inherited_dynamic / prediction / modelled_completion / context). principal_evidence is yes only for recorded Orchidea. Iowa that used same-dynamic L is modelled_completion, not inherited. Philharmonia and McGill are context — never principal.
  • Media is family-specific (§5.6). String books: arithmetic mean of populated IOWA/ORCH peers. Woodwind ordinario: default empirical_only; equal_weight / legacy_equal_weight only when selected. A single-source cell is that source, not half of it. Shared string L does not increase evidential strength for the relative effect. Use Summary_Empirical_ORCH for published string technique statistics.
  • Measured ceiling (violin): MIDI 100. reporting_status = above_measured_ceiling; AcousticTable cell_status = register_extrapolated, validation_status = review_required. Summary_Measured_Range uses only the rows at or below the ceiling (completed grid, not principal evidence).
  • IOWA effects: no recordings. Every IOWA effect cell is modelled_IOWA_anchored. Evidence_Map is modelled_completion when same-dynamic anchors taught that layer; inherited_dynamic only when a donor (usually mf) was reused.
  • Sul tasto and other extra-collection techniques: if IOWA/Orchidea lack a technique, Philharmonia or McGill may teach \(L=\ln(\mathrm{effect}/\mathrm{ordinario})\) (v1.5.5). Production outputs stay pp/mf/ff; eligible donor dynamics are kept independently. A missing CORE layer takes the closest eligible donor (exact dynamic, then scale distance, then more anchors, then ORCH > PHIL > McGill). A single teacher (e.g. p) is still transposed via arco-normal dynamic ratios. l_donor_dynamic records that choice. l_invariance compares note-wise \(L\) on shared MIDI inside one collection; it is not a transfer gate. The \(0.40\) nat cutoff is a heuristic on \(\max|L_{d_0}-L_{d_1}|\), not a validated invariance test. A leftover from another collection is ignored when Orchidea already teaches a CORE dynamic. Absolute Phil/McGill CDM never enter Media. A nested arco-sul-tasto book is sul tasto, never ordinario. Measured sul tasto may teach its own technique.
  • Con sordino: if Rebuild finds an Orchidea con-sord tree (cello, violin, bass, …), every recorded dynamic (pp/mf/ff) is Empirical_ORCH and is not modelled. Viola has no Orchidea mute — McGill muted / McGill ordinario is prediction only. Never invented.
  • Philharmonia / McGill: context layers in STE workbooks; omitted from Zenodo Media and from Empirical_ORCH.

6.6 Comparative analysis (análise_v2)

Folder: D:\CORDAS_2\VIOLIN\Violino - análise_v2. Rebuild: python _build_violin_analysis_v2.py.

In plain words

The analysis folder can line the five approaches up and compare F-061 to ordinary bowing. Treat Media headlines as a completed-grid description. For a paper, quote Empirical_ORCH (measured Orchidea) and keep tasto / inherited dynamics in a prediction section.

For the specialist

Paired field on collection × dynamic × MIDI. Primary support G3–E7 (MIDI 55–100). Comparative support G5–E7 so harmonics enter. Aggregates: geometric mean of ratios = exp(mean L). Uncertainty: 3000-draw bootstrap percentile CI on mean L, mapped back to percent. Registral trend: Theil–Sen of L (and of ln CDM for arco). Pairwise: Wilcoxon signed-rank on paired notes; effect size Cliff’s δ. Omnibus: Friedman on the five Media-mf L-curves. Fingerprints: PCA and average-linkage RMSE of L(midi). Arco is included as the identity L ≡ 0 and as its own absolute-CDM series.

Completed-grid Media mf (not principal evidence): ponticello +10.8% on G3–E7; sordino −5.0%; tasto +2.9% (prediction); harmonics −19.0% on G5–E7. Prefer the measured Orchidea mf figures: sordino about −6.5% (n≈42), ponticello about +6.6% (n≈37), harmonics about −18.7% (n≈18). Those are F-061 shifts, not “19% less richness.”
