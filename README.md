# Ratio_extrapol

Local folder: `Ratio_Extrapol`. GitHub: [LuisMRaimundo/Ratio_extrapol](https://github.com/LuisMRaimundo/Ratio_extrapol).

Python package `ste_lab` (v1.5.1) and the GUI title “STE Lab” are leftover identifiers. They are not a second product.

This repository estimates Combined Density Metric (F-061 / `spectral_mass`) curves across technique, collection, and missing notes. It does **not** compute F-061 from audio. Engineering consistency of exports is not a claim of acoustic validity.

Historical research workbooks were **not** regenerated by the export-consistency work.

## Family Media policies

Production Media uses only IOWA and ORCH. Philharmonia and McGill are context, never a third vote.

| Family | Policy |
|--------|--------|
| Bowed strings | Arithmetic mean of present IOWA/ORCH values. One present value is kept, not halved. Neither present is missing, not zero. |
| Woodwind ordinario | `calibration.yaml` combination. Default `empirical_only`: keep a valid target empirical value; use transfer only when that value is absent. |

Supported combination modes: `empirical_only`, `equal_weight` (0.5/0.5), `legacy_equal_weight` with \(w_T = 1 - w_E\). `fixed_weight` and `validation_optimised` are rejected. `optimal_weight()` is a research helper only.

A weighted mix of empirical and modelled inputs is `COMBINED_ESTIMATE`, not `MEASURED`.

The same resolver writes in-memory Media, Zenodo Media, AcousticTable, and Final_Calibration.

## Fill

`fill_missing` interpolates inside the measured MIDI span and may continue outside it up to `max_extrap_semitones` (default 12). It is not interior-only.

- PCHIP: at least 3 known points; exterior origin `extrapolated_pchip` (not ridge). Two points raise `InsufficientFillData`; the layer is unchanged.
- Linear: exterior hold, origin `extrapolated_hold`.
- Polynomial: origin `extrapolated_polynomial`.

Technique transfer still holds edge \(L\). That operator was not changed to match Fill.

## Discovery (v1.5.1)

`collect_compiled_specs` never invents sul tasto. Any compiled research book whose path contains `tasto` is excluded **before** technique assignment and **before** the PHIL/MCGILL “no technique → ordinario” fallback. Skipping only a top-level folder named `sul-tasto` is not enough: a nested Philharmonia `arco-sul-tasto` tree must not be ingested as `ordinario`. Those source workbooks are left untouched; rebuild the generated preparatory / STE books.

## Transfer relations (v1.5.0)

Technique, instrument, and collection log-ratios share one `Relation` record (`ste_lab/relations.py`). **Media is always mean(IOWA, Orchidea).** Extra collections (Philharmonia, McGill, …) enrich that Media only through \(L=\ln(\mathrm{effect}/\mathrm{ordinario})\) when anchors overlap (`transfer_field.mode: pooled`, the default). Their absolute CDM never enters Media. `mode: single` is the one-teacher field (1.4.0 / published books).

## \(L_{\mathrm{coll}}\)

Production two-log-ratio transfer applies only \(L_{\mathrm{instr}}\) to the ORCH sibling donor. \(L_{\mathrm{coll}}\) is stored as a diagnostic. Do not multiply by \(\exp(L_{\mathrm{coll}})\).
